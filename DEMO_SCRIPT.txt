[1:00 — ARCHITECTURE]
(show assets/architecture_diagram.png)
Let us walk through the architecture diagram showing how data flows through the system.
First, a raw incident report enters the parse_input node, where it is parsed and normalized.
Next, it must pass the security_checkpoint gatekeeper. This node scrubs PII and checks for prompt injections or restricted material requests.
If it is clean, the report is passed to the orchestrator_agent node, which coordinates the core review.
The orchestrator delegates work to the resource_allocator sub-agent to vet supplies, and the safety_evaluator sub-agent to assess route hazards.
These sub-agents automatically call the stdio MCP Server to look up live weather, check warehouse inventory, and check road blockages.
Finally, the consolidated Incident Action Plan is sent to the human_review node where the workflow pauses for commander approval before finalize_response sends the dispatch signal.
